## ⚡ Overview

This repository hosts the source code for **[harsh-hak.github.io](https://harsh-hak.github.io/)**, showcasing security engineering research, AI-assisted threat hunting platforms, custom offensive/defensive tools, and verified industry credentials.

- **Design Philosophy**: Minimalist Cyber / Neo-Brutalist aesthetics (Scarlet Red `#F5332C`, Pure Black `#000000`, and Creme `#CCC8B9`).
- **Core Focus**: AI Security (LLM/SLM evaluation), SIEM log correlation, network reconnaissance, and malware static analysis.

---

## 🌟 Key Features

- **Interactive Cyber Terminal**: Built-in CLI-style navigation and command-line portfolio interaction.
- **Dynamic Particle Matrix Canvas**: Custom 60fps HTML5 Canvas background with connected graph nodes.
- **Project Directory**: Live demos and repositories for tools like **Sentry-AI** (Wazuh SIEM + Local LLM copilot), **ShadowScan** (Async network recon), and **Malware Analyzer X** (ELF static forensics).
- **Academic Research & Publications**: Highlighting peer-reviewed IEEE papers and AIMT research posters.
- **Brutalist Credentials Hub**: Verified badges for CompTIA Security+, AWS Solutions Architect Associate, Oracle Cloud Infrastructure AI Certified Foundations, and more.
- **Live Telemetry & Activity**: Real-time GitHub commit activity and TryHackMe telemetry.
- **Robust SEO & PWA Ready**: OpenGraph metadata, structured JSON-LD schemas, and `react-helmet-async` header orchestration.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Local Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harsh-hak/harsh-hak.github.io.git
   cd harsh-hak.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
